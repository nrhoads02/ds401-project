# Data Transformation

The modules in this folder are responsible for cleaning, adjusting, and enriching the raw data with technical indicators and other relevant features.

## Modules

* **`stock_adjustments.py`**: Contains functions to handle stock splits. It adjusts historical OHLCV data (open, high, low, close, volume) and option strike prices based on split events recorded in the `split` dataset. It also includes logic to identify and remove potentially duplicated split records.
* **`technical_indicators.py`**: Calculates a wide range of technical indicators based on the OHLCV data. This includes moving averages (SMA, EMA), standard deviation, RSI, ATR, realized variance measures (like Parkinson-plus-jumps), OBV, CMF, CCI, VWAP, and forward-looking targets for volatility and returns used in modeling. See `INDICATORS.md` for detailed formulas.
* **`cboe_index_join.py`**: Joins historical data from various CBOE volatility indices (like VIX, VIX9D, VVIX, etc., located in `data/raw/cboe`) to the main stock data DataFrame based on the date.
* **`transformation_pipeline.py`**: Orchestrates the data transformation process by applying split adjustments, calculating technical indicators, and joining CBOE index data. It leverages Polars' streaming capabilities to optimize memory usage during these potentially intensive operations.
* **`INDICATORS.md`**: Provides detailed documentation for all technical indicators generated by `technical_indicators.py`, including formulas and column names.

## Usage

To apply the standard set of transformations (split adjustments, technical indicators, CBOE index joins) to an existing OHLCV Polars DataFrame, use the `transformation_pipeline` function within the `transformation_pipeline.py` module. This function serves as the primary entry point for the transformation process.
