# Technical Indicators Documentation

This document explains all technical indicators and columns generated by `technical_indicators.py`. Each indicator includes its name, column label, and exact computation method.

---

## 1. **Log Returns**
**Column**: `log_returns`  
**Formula**:  
If previous close and current close > 0:  
`log_returns = log(close / close_prev)`  
Else: `None`

---

## 2. **Positive and Negative Log Returns**
**Columns**: `pos_returns`, `neg_returns`  
**Formula**:  
`pos_returns = max(log_returns, 0)`  
`neg_returns = max(-log_returns, 0)`

---

## 3. **Simple Moving Average (SMA)**
**Column**: `SMA_n` (e.g., `SMA_10`)  
**Formula**:  
`SMA_n = rolling_mean(close, window=n)`

---

## 4. **Exponential Moving Average (EMA)**
**Column**: `EMA_n`  
**Formula**:  
`EMA_n = ewm_mean(close, span=n, adjust=False)`

---

## 5. **Rolling Standard Deviation**
**Column**: `STD_n`  
**Formula**:  
`STD_n = rolling_std(close, window=n)`

---

## 6. **SMA to EMA Ratio**
**Column**: `SMA_EMA_ratio_n`  
**Formula**:  
`SMA_EMA_ratio_n = SMA_n / EMA_n`  
(If `EMA_n < 1e-6`, set ratio to `1.0`)

---

## 7. **Price Delta**
**Column**: `price_delta`  
**Formula**:  
`price_delta = close - close_prev`

---

## 8. **RSI (Relative Strength Index)**
**Column**: `RSI_n`  
**Formula**:  
Let `gain = max(price_delta, 0)`  
Let `loss = max(-price_delta, 0)`  
Let `avg_gain = rolling_mean(gain, n)`  
Let `avg_loss = rolling_mean(loss, n)`  
Then:  
`RSI = 100 - 100 / (1 + avg_gain / avg_loss)`  
Clipped to [0, 100]

---

## 9. **Average True Range (ATR)**
**Column**: `ATR_n`  
**Formula**:  
`TR = max(high - low, abs(high - close_prev), abs(low - close_prev))`  
`ATR_n = rolling_mean(TR, window=n)`

---

## 10. **Parkinson Plus Jumps Daily Variance**
**Column**: `parkinson_plus_jumps_daily`  
**Formula**:  
Let `k = 1 / (4 * log(2))`  
- `intraday = k * (log(high / low))^2`  
- `oc_jump = (log(close / open))^2`  
- `overnight_jump = (log(open / close_prev))^2`  
Sum:  
`parkinson_plus_jumps_daily = intraday + oc_jump + overnight_jump`

---

## 11. **Rolling Realized Variance**
**Column**: `rv_hd` (e.g., `rv_10d`)  
**Formula**:  
`rv_hd = rolling_sum(parkinson_plus_jumps_daily, window=h)`

---

## 12. **Forward Realized Variance**
**Column**: `rv_hd_future`  
**Formula**:  
`rv_hd_future = rv_hd shifted -h days into future`  
**Note**: This is what we use for RV when training our models.

---

## 13. **Forward Log Returns**
**Column**: `log_ret_future_h`  
**Formula**:  
`log_ret_future_h = rolling_sum(log_returns, window=h) shifted -h days into future`  
**Note**: This is what we use for `k` when training our models.

---

## 14. **Typical Price**
**Column**: `typical_price`  
**Formula**:  
`typical_price = (high + low + close) / 3`

---

## 15. **Chaikin Money Flow (CMF)**
**Column**: `CMF_n`  
**Formula**:  
`money_flow_multiplier = (close - low) / (high - low)`  
`money_flow_volume = money_flow_multiplier * volume`  
`CMF_n = rolling_sum(money_flow_volume, n) / rolling_sum(volume, n)`  
Clipped to [-1, 1]

---

## 16. **Commodity Channel Index (CCI)**
**Column**: `CCI_n`  
**Formula**:  
`tp_sma = rolling_mean(typical_price, n)`  
`tp_dev = typical_price - tp_sma`  
`tp_mad = rolling_mean(abs(tp_dev), n)`  
`CCI_n = tp_dev / (0.015 * tp_mad)`  
Clipped to [-666.667, 666.667]

---

## 17. **On-Balance Volume (OBV)**
**Column**: `OBV`  
**Formula**:  
If `close > close_prev`: `volume_direction = +volume`  
If `close < close_prev`: `volume_direction = -volume`  
Else: `0`  
`OBV = cumulative_sum(volume_direction)`

---

## 18. **OBV Change**
**Column**: `OBV_change_n`  
**Formula**:  
`OBV_change_n = OBV - OBV.shift(n)`

---

## 19. **Volume-Weighted Average Price (VWAP)**
**Column**: `VWAP_n`  
**Formula**:  
`VWAP_n = rolling_sum(typical_price * volume, n) / rolling_sum(volume, n)`

---

## 20. **VWAP Deviation**
**Column**: `VWAP_deviation_n`  
**Formula**:  
`VWAP_deviation_n = close - VWAP_n`

---
